# Whole-site Preview design review

This pass is for JJ's review before any Production decision. About's résumé CTA is removed; the direct route, editor and print behavior remain. Portfolio and Learn now have distinct split heroes. Blog features one post above the remaining tiles without duplicating it.

## Reference and reasoning

The [saved Design Preferences and Adham Dannaway Reference](https://chatgpt.com/space/page_6ac13e4d41bc81918c72d36a3432b401) was read, along with the local portfolio direction and page design notes. Its distinctions between JJ's choices, author guidance, observed composition and inferred applications are retained. The saved Adham homepage and About screenshots were visually inspected. Atlas independently inspected all six latest user screenshots and supplied the Portfolio/Learn composition findings. The six screenshots could not be materialized on this Mac; Library reads returned image references rather than local pixels. This consumer does not claim to have inspected those unavailable files directly.

The useful principles here are deliberate hierarchy, proximity/alignment for grouping, a small consistent type/colour/spacing system, concise literal copy, readable line spacing, honest individual contributions and relevant visual anchors. The current design uses these as reasons for decisions; it does not treat a screenshot, accessibility score or deployment as aesthetic approval.
